O que são listas no HTML ?

Uma lista é uma sequencia de itens relacionado entre si.

No HTML, existem principalmente tres tipos de listas . Listas não ordenadas , listas de descrição .

Lista não ordenada (ul)

Uma lista não ordenada é usada quando a ordem dos elementos/itens não importa

  • Arooz
  • Feijão
  • Macarrão
  • Carne
  • Café

Lista ordenada (ol)

Usamos uma lista ordenada quando os itens possuem uma sequencia, uma classificação ou uma ordem que precisa ser respeitada.

  1. Ferver a água
  2. Colocar o café no filtro
  3. Despejar a água quente
  4. Servir o café

Lista de descrição (dl)

Usamos uma lista de descrição quando precisamos descrever algum termo.

Para criarmos essa lista, utilizamos tres elementos:

  • DL(description list) : Representa a lista de descrição
  • DT(description term) : Representa o termo
  • DD(data description) : Representa a descrição do termo
