Aprendendo sobre elementos textuais

O que são os elementos textuais ?

Os elemntos textuais servem para destacar, enfatizar ou dar um significado a partes especificas do conteúdo

Elemento strong

É muito importante aprender a estrutura do HTML

A tag strong(forte) é utilizada para indicar que determinado trecho possui forte importancia.

Elemento B

Aprenda HTML , CSS e JavaScript para criar páginas web.

A tag B(bold) também costuma deixar o texto em negrito, mas sua finalidade é criar apenas um estilo/destaque visual

Elemento EM

Voce realmente precisa estudar

O elemento EM comunica que aquele trecho deve receber uma determinada enfase dentro da frase

Elemento I

o termo software é utilizado com frequencia na área de tecnologia

O elemento I possui a mesma formatação visual que o elemento EM, porém, não possui valor semantico. É apenas estilo visual
